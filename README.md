# 配膳お知らせアプリ

設置時間の指定分数前になると、スマホのホーム画面に自動でお知らせが届くアプリです。
「配達完了にする」を押したときも、完了の通知が届きます。

中身のスケジュールは `2026配膳発注システム.xlsx` の「発注・配達管理」シート（77件）をそのまま取り込み済みです。

## 公開手順（GitHub Pages・無料・登録のみで維持費なし）

1. https://github.com にアクセスし、アカウントを作成（お持ちでなければ）してログインする。
2. 右上の「+」→「New repository」で新しいリポジトリを作成する。
   - Repository name: 例 `haizen-oshirase`（何でもOK）
   - Public を選択
   - 「Create repository」をクリック
3. できたリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）をクリックする。
4. このフォルダの中身を **フォルダごとではなく中の6つのファイル・フォルダを** そのままドラッグ＆ドロップする。
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons`（フォルダごと）
5. 「Commit changes」をクリックしてアップロードを確定する。
6. リポジトリの「Settings」タブ →左メニューの「Pages」を開く。
7. 「Build and deployment」の「Branch」を `main`（または `master`）、フォルダは `/ (root)` を選んで「Save」。
8. 1〜2分待つと、ページ上部に公開URLが表示されます（例: `https://ユーザー名.github.io/haizen-oshirase/`）。これが本番のアプリURLです。

## iPhoneでの使い方

1. 上記URLをSafariで開く。
2. 下部の共有ボタン（□に↑）→「ホーム画面に追加」をタップ。
3. **必ずホーム画面に追加したアイコンから** アプリを開く（Safariのタブから直接開くと通知が使えません）。
4. アプリ上部の「通知を有効にする」をタップし、通知を許可する。
5. 右上の ⚙ から「日程（実際の日付）」に、前日・1日目・2日目・3日目の実際のカレンダー日付を入力する。ここを入れないと自動通知は発火しません。
6. 通知タイミング（何分前に知らせるか）も同じ画面で選べます。

## 大事な制約（iPhone・サーバーなし版の限界）

- アプリを完全に終了（スワイプで消す）すると、その間はタイマーが動かず、通知は届きません。
- アプリを開いている間・ホーム画面から開いた直後は、時間になった予定の通知（当日中に見逃した分も含む）がまとめて届きます。こまめに開く運用にしてください。
- 来年以降も使い回す場合は ⚙ →「全件を『発注済』に戻す」でリセットし、日程の日付だけ入れ直せば再利用できます。
